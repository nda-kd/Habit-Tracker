# 🌱 Habit Tracker

A simple and intuitive **habit tracking application** built with **React, TypeScript, and Vite**.

The goal of this project is to create a clean and easy-to-use application for building consistent habits, tracking daily progress, and visualizing long-term results.

> 🚧 **Work in Progress:** This project is currently under active development. The current version represents the early stage of the application, with additional functionality planned for future iterations.

## ✨ Planned Features

The application is being designed around the following features:

* 📅 Daily habit tracking
* ✅ Mark habits as completed
* 📊 Statistics and progress tracking
* 🗓️ Calendar-based habit overview
* 📈 Visualize habit consistency over time
* 🎯 Create and manage personal habits
* 📱 Responsive user interface

More features will be added as development continues.

## 🔮 Future Backend

One of the main goals of this project is to eventually turn it into a **full-stack application**.

The planned backend will be developed using **Java and Spring Boot**, providing a REST API for the React frontend.

The backend is planned to handle:

* 🔐 User authentication and authorization
* 👤 User accounts
* 🌱 Habit creation and management
* 📅 Daily habit records
* 📊 Historical statistics
* 💾 Persistent data storage
* 🔄 REST API communication with the React frontend

The exact database technology will be decided as the backend development begins.

## 🚀 Getting Started

As the project is currently in an early stage, setup instructions may change during development.

### Clone the Repository

```bash
git clone https://github.com/nda-kd/Habit-Tracker.git
```

Navigate to the project:

```bash
cd Habit-Tracker
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.
